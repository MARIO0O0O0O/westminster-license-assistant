Executive Presentation

Westminster Business License Assistant (WBLEPA)

AI-Powered Municipal Permitting Guidance & Navigation System

  • Author: Mario Espindola, MPA, IPMA-SCP
  • Target: City of Westminster, CA — Economic Development Division
  • Purpose: No-cost, independent proof-of-concept AI work sample
  • Status: Fully deployed, validated, and publicly accessible
Part 1: Research

Identifying Public Pain Points

Structured review of Westminster's public business licensing channels revealed critical friction points:

  • Multi-System Fragmentation: Users navigate City site, HdL portal, and CalGold separately.
  • Eligibility Ambiguity: Title 5 rules (e.g. leasing 3+ residential units) easily missed.
  • Partner Confusion: 12+ economic development partners without clear matching.
  • Static Language Files: Language resources locked in static PDFs without search.
Part 2: Strategy

AI Solution & Zero-Cost Value Proposition

A targeted RAG assistant addresses friction without municipal investment:

  • Unified Navigation: Consolidates 3 public systems into one conversational tool.
  • Plain-Language Answers: Converts legalistic code into plain-language steps.
  • Zero Financial Impact: $0 cost to City — built on free-tier infrastructure.
  • Zero Staff Burden: Requires no City IT setup or vendor contract modifications.
Part 3: Architecture

Four-Layer System Architecture

Built with modern, open-source AI engineering practices:

  • Data Layer: 7 public source HTML snapshots parsed into 22 SQLite chunks.
  • Retrieval Engine: SQLite FTS5 full-text search with topic-tag boosting.
  • AI Generation Layer: Google Gemini API with strict citation mandate `[chk_id]`.
  • User Interfaces: Responsive Web UI (Next.js/JS) and Termux CLI client.

Part 5: Validation

Empirical Testing & Security Results

Rigorously evaluated for accuracy, safety, and performance:

  • 100% Top-5 Retrieval Accuracy: Verified across 8 persona test questions.
  • 100% Citation Faithfulness: Zero fabricated claims across all answers.
  • 13/13 E2E Integration Suite Passed: Tested empty inputs, long inputs, and prompt injection.
  • Automated Maintenance: Weekly scheduled scraper refresh via GitHub Actions.
Part 6: Governance

Known System Limitations

Transparent scope boundaries appropriate for a work sample:

  • English-Only Launch: Spanish and Vietnamese identified for future expansion.
  • 22-Chunk Corpus Boundary: Covers core business licensing public pages.
  • Rate Limited: Enforces 15 req/min cap to protect free-tier API quotas.
  • Informational Disclaimer: Non-binding guidance; users verify with City staff.

Recommendations & Next Steps
