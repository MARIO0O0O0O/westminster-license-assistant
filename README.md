# Westminster Business License Eligibility & Pathway Assistant (WBLEPA)

An AI-powered assistant designed to guide Westminster, CA business owners, landlords, and contractors through business licensing, permit applicability, and application pathways using public city and state data.

## Project Description
Westminster's licensing process is spread across multiple systems (City website, HdL portal, CalGold state permit lookup). WBLEPA unifies guidance using RAG and LLM synthesis to provide clear, source-cited eligibility guidance.
